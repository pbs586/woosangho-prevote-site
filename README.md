# 강원특별자치도지사 후보 우상호 · 사전투표소 안내

> **강원도가 특별해지는 순간** — 대통령이 보낸 사람, 기호 1번 우상호

강원특별자치도민을 위한 제9회 전국동시지방선거 **사전투표소 안내** 정적 웹페이지입니다.
중앙선거관리위원회 선거통계시스템 오픈 데이터를 기반으로, 18개 시·군의 모든 사전투표소를 한 페이지에서 빠르게 검색할 수 있습니다.

## ✨ 주요 기능

- **페이스북 스킨 풀블리드 히어로** — 캠페인 공식 배너 그대로 노출
- **함께 뛰는 우리 후보 18인 갤러리** — 강원 18개 시·군 시장/군수 후보 포스터 그리드
- **시·군 한 번에 선택** — 후보 얼굴 + 시·군명 + 투표소 개수가 보이는 인터랙티브 그리드
- **빠른 텍스트 검색** — 읍·면·동, 투표소명, 건물명, 주소 동시 검색
- **사전투표소 카드** — 주소, 편의시설(승강기·점자블록 등), 중앙선관위 약도 링크
- **반응형** — 데스크탑·태블릿·모바일 모두 최적화
- **OG/트위터 메타** — SNS 공유 시 우상호 후보 이미지 미리보기

## 🚀 배포 방법

### GitHub Pages

1. 이 저장소를 GitHub에 푸시
2. Settings → Pages → Source를 `main` 브랜치 / `root`로 설정
3. 발급되는 URL(`https://<username>.github.io/<repo>/`)로 접속

### 로컬 실행

별도 빌드 없이 `index.html`을 브라우저로 열기만 하면 됩니다.

```bash
# 또는 간단한 로컬 서버
python -m http.server 8000
# → http://localhost:8000
```
